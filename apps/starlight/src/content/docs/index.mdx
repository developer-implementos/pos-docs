Una plataforma POS corporativa para **Chile, Perú y España**, con módulos de negocio compartidos y adaptadores para las diferencias de cada país. Esta guía reúne la arquitectura propuesta, la implementación del monorepo y la evidencia del sistema actual. Las fuentes técnicas se mantienen en [POS Docs](https://github.com/developer-implementos/pos-docs); el código del producto pertenece a <a href={productRepositoryOrigin}>POS Platform</a>. La documentación distingue la revisión editorial de la revisión del código que describe.

## Estado del material

| Categoría | Qué representa |
| --- | --- |
| **Propuesta** | Diseño objetivo y recomendaciones con su estado de decisión. No acredita una implementación productiva. |
| **Sistema actual y evidencia** | Comportamientos observados en fuentes y snapshots de repositorios. Su correspondencia con producción debe confirmarse. |
| **Operación y validación** | Escenarios de recuperación, condiciones de aceptación y datos pendientes para cerrar el diseño. |
| **Implementación y desarrollo** | Estructura, comandos y controles documentados en el repositorio; cada guía declara las capacidades disponibles y sus límites. |

Cada página identifica su alcance. El [estado de implementación y las decisiones pendientes](/guide/overview/#estado-de-la-propuesta) distingue la demostración frontend, la base backend y el producto objetivo. IA y RFID se consultan como **extensiones opcionales**.
