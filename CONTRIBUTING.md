# Contribuir a POS Docs

POS Docs mantiene las fuentes editoriales y el portal público de POS Platform. Para iniciar o retomar una contribución, leer [AGENTS.md](AGENTS.md) y usar el procedimiento compartido `pos-delivery` allí enlazado.

- El [sistema documental](docs/documentation-system.md) define qué fuente es propietaria, cómo coordinar cambios con el producto y cómo identificar evidencia y revisión editorial.
- La [plantilla de PR](.github/pull_request_template.md) y los [controles editoriales](tools/editorial/README.md) describen la declaración, los recorridos y su verificación.
- La [política de protección e integración](.github/rulesets/README.md) mantiene las reglas de revisión, CI y squash. Consultarla antes de integrar; este documento no establece otra política.
- Los cambios de producto, contratos y avance siguen las [reglas de POS Platform](https://github.com/developer-implementos/pos-platform/blob/main/CONTRIBUTING.md). Una PR editorial enlaza su issue sin cerrar entregables ni atribuir aceptación operativa.

La [guía de desarrollo local](README.md#desarrollo-local) reúne los comandos editoriales. Registrar alcance, evidencia y límites en la PR; conservar las decisiones sustanciales según el [procedimiento ODD](odd/README.md).
