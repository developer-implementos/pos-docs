Abrir y editar

  1. Descarga un archivo .excalidraw o el atlas con las siete vistas.
  2. Abre Excalidraw y utiliza Abrir en su menú o Ctrl + O para elegir el archivo. En macOS, ⌘ + O.
  3. Edita el diagrama y guarda una copia del archivo para conservar tus cambios.

Consultar sin conexión

Esta galería y sus SVG funcionan con archivos locales, sin dependencias externas. Conserva los archivos juntos al extraer el ZIP.

Las vistas previas mantienen el tamaño del dibujo: desplázate dentro de ellas para leerlo o abre el SVG completo. Puedes enfocar una vista con el teclado y usar las flechas para desplazarla.

Una propuesta para revisar y evolucionar

Angular + Tauri es la dirección elegida para el cliente. Backend, datos, sincronización, integraciones y despliegue describen el diseño recomendado. La propiedad de maestros por país, los contratos de proveedores, la infraestructura y los objetivos de recuperación siguen sujetos a validación.

El perfil inicial contempla pérdida de WAN con LAN y servidor de sucursal disponibles. Consulta la guía del modelo C4 y el alcance de esta colección antes de interpretar un diagrama como una decisión de implementación.
